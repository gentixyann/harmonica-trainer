# VCSL C harmonica samples

These WAV files are unmodified normal-sustain recordings selected from the
Versilian Community Sample Library (VCSL):

- Source: https://github.com/sgossner/VCSL
- Upstream directory: `Aerophones/Free Aerophones/Harmonica-Hohner-Special20-C/Sustains/Normal`
- Instrument recorded by VCSL: Hohner Special 20 in C
- License: CC0 1.0 Universal; see `LICENSE.txt`

The application repitches the nearest recording and plays two slightly detuned
voices to approximate the beating of a tremolo harmonica. TOMBO and Hohner
product names identify the intended and sampled instruments respectively; no
endorsement or affiliation is implied.
